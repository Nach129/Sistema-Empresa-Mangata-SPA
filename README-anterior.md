# Sistema Empresa Mangata SPA

Sistema web para la gestión de usuarios, productos, pedidos y reportes de Mangata Design SPA.

## Estado del proyecto

Proyecto creado para el desarrollo de la Práctica Profesional I de la carrera de Ingeniería Civil en Computación e Informática de la Universidad de Tarapacá.

Actualmente, el proyecto se encuentra en etapa inicial de análisis y planificación.

## Módulos considerados

- Módulo de usuarios.
- Módulo de pedidos.
- Módulo de productos.
- Módulo de reportes y estadísticas.

## Tecnologías previstas

- Angular.
- TypeScript.
- HTML.
- CSS.
- Supabase.
- PostgreSQL.
- Chart.js.
